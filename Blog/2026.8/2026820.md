# 博客搭建记录

> 日期：2026-08-20

## 项目概述

记录一次个人博客的搭建过程，包含页面设计、前端结构以及文章管理方式的实现。

## 设计与实现

- 采用纯静态架构，基于 HTML、CSS 和 JavaScript 构建，无需后端服务。
- 页面使用毛玻璃视觉风格与雾蓝色调，保持简洁的阅读体验。
- 文章数据通过 JSON 文件管理，前端动态加载文章列表。
- 文章内容使用 Markdown 编写，并通过解析器转换为页面内容。

## 开发过程

搭建过程中主要围绕页面结构、样式设计、文章加载逻辑以及文件组织方式进行调整。

部分问题包括：

1. `fetch` 无法直接读取 `file://` 下的本地文件，需要通过本地服务器环境运行。
2. 文章路径与数据索引需要保持对应关系，否则会出现加载失败。
3. 毛玻璃效果依赖浏览器渲染能力，需要考虑不同设备上的性能表现。

## 后续方向

- 优化移动端显示效果
- 持续记录更多内容

## 结语
